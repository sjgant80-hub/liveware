Plant the seed

A seed is a small signed file that grows the whole system. It checks its own signature and every block's hash before a line runs, reproduces a byte-identical copy of itself, and refuses to grow if a single byte is changed.

What this does not prove: autonomous spread — by design it does not copy itself anywhere; copying is your click. And whoever holds the signing key can sign a new seed.

How the proof works

Sealed claims

The pass criteria were written and committed before any code that measures them. The measurement refuses to run if the sealed file changed, and the commit is on this page.

Receipts

Each test writes a record of its inputs, outputs and verdict; its id is the SHA-256 of that record. Your run's id must match the expected id shown beside each test.

CI reproduces it

GitHub Actions runs the same four tests headlessly on every change and publishes the receipts. A third party reproduces the result, not just us.

Mutation testing

The witness plants a bug in every kernel and fails the build unless a test catches it — proof the tests are real, not decoration. Failures are kept on the record, never hidden.

Re-run it yourself 
git clone https://github.com/sjgant80-hub/liveware
cd liveware
node --test test/*.test.mjs        # the kernels
node tools/measure.mjs --check     # re-derive the four receipts, byte for byte
